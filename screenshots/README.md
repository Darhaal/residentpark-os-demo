# Screenshots

Three images power the **Product preview** table in the root [`README.md`](../README.md).
Capture them from the live demo (or a local run), then commit them here with these exact
filenames:

| File | Page | How to capture |
| --- | --- | --- |
| `admin-parking-map.png` | Admin → Parking, floor **D1** | Sign in as admin, open the parking map on floor D1 (the spatial garage plan with zones and lanes). |
| `resident-dashboard.png` | Resident dashboard (`/`) | Sign in as the resident (`demo.alice`); capture the dashboard showing the vehicle and parking summary. |
| `admin-dashboard.png` | Admin → Reports | Sign in as admin; capture the occupancy/reports view. |

Recommended: **1440×900** viewport, light theme, PNG, browser chrome cropped out.

Add all three **before** making the repository public, otherwise the README shows broken
image icons.
